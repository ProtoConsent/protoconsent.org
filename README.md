Source for [protoconsent.org](https://protoconsent.org), the official website for the [ProtoConsent](https://github.com/ProtoConsent/ProtoConsent) browser extension.

## What this site covers

- Project overview, features, and screenshots
- [Blocklists](https://protoconsent.org/lists.html) with subscription URLs for Pi-hole, AdGuard, uBlock Origin, NextDNS, and more
- [Developer guide](https://protoconsent.org/developers.html) for the SDK and `.well-known/protoconsent.json` site declarations
- [Declaration validator](https://protoconsent.org/validate.html) and [generator](https://protoconsent.org/generate.html)
- [Site directory](https://protoconsent.org/directory.html) of sites publishing declarations
- [Blog](https://protoconsent.org/blog/) with technical deep-dives

## Hosting

Static HTML/CSS served via GitHub Pages. No build step, no dependencies.
